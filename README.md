# MOA 졸업작품 소스

국내·미국 금융정보를 한 화면에서 탐색하기 위한 웹 애플리케이션의 코드 검토용 공개본입니다. 화면 구조, 데이터 공급자 분리, 차트와 섹터맵, 기업 자료 조회, SQLite 저장 구조와 회귀시험을 살펴볼 수 있습니다.

이 공개본에는 실제 시세·공시·리포트·기사 본문, 운영 DB, API 키, 계정 세션이 들어 있지 않습니다. 기본 실행은 외부 요청과 자동 수집을 차단한 로컬 미리보기입니다. **데이터가 비어 있거나 연결 필요·표시 제한으로 나오는 것이 정상입니다.** 실제 데이터를 꾸며 채우지 않습니다.

## 실행

Node.js 24 LTS와 pnpm 10 이상을 권장합니다. 의존성이 요구하는 최소 Node 버전은 22.13.0입니다. 운영체제에 맞는 Node와 pnpm을 먼저 설치한 다음 프로젝트 폴더에서 실행합니다.

```sh
pnpm install --frozen-lockfile
pnpm build
pnpm dev
```

브라우저에서 `http://127.0.0.1:4181`을 엽니다. `pnpm start`도 같은 안전 미리보기를 실행합니다. 의존성을 처음 설치할 때에는 패키지 레지스트리 접속이 필요합니다. 설치를 마친 뒤 빌드와 미리보기는 외부 금융 API나 AI 서비스를 필요로 하지 않습니다.

포트를 바꾸려면 `node scripts/public-preview.mjs --port=4182`를 사용합니다. 또는 셸에서 `MOA_PREVIEW_PORT`를 지정할 수 있습니다. `.env.example`은 안내용이며, 실행기는 `.env`를 읽지 않습니다. 실제 키를 입력할 필요가 없습니다.

첫 실행 시 이 공개본 안의 `.preview-runtime/public-preview.sqlite`에 빈 스키마와 로컬 상태가 만들어집니다. 기존 DB 경로를 지정하는 옵션은 없습니다. 서버는 `127.0.0.1`에만 바인딩합니다. 종료는 `Ctrl+C`입니다.

## 코드에서 확인할 수 있는 구성

| 영역 | 구현 위치 | 공개본의 기본 동작 |
| --- | --- | --- |
| 화면·탐색 | `dist/index.html`, `dist/js/app.js`, `dist/styles/` | 메뉴와 빈 상태 화면 확인 |
| 차트·분석 도구 | `dist/js/stock-chart*`, `dist/js/analysis-chart*` | 계산·상태 관리 코드 및 합성 시험 제공 |
| 섹터맵·순위 | `dist/js/sector*`, `server/providers/` | 데이터 공급 계약과 변환 코드 확인 |
| 기업 사업·재무 자료 | `server/business-profile*`, `server/stock-workbench*` | 저장 자료가 없어 빈 결과 반환 |
| 일정·리포트·공시 | `server/calendar*`, `server/reports.mjs`, `server/*filings*` | 실제 수집 자료와 PDF 없음 |
| API·서버 | `server/api.mjs`, `server/node-http.mjs` | 원본 서버 구조를 재사용하는 로컬 API |
| 저장 구조 | `db/`, `drizzle/`, `server/sqlite-adapter.mjs` | 새 SQLite DB에 스키마 적용 |
| 시험 | `tests/`, `tests/fixtures/` | 선별한 합성·격리 시험 |

`dist/js`, `dist/styles`, `dist/index.html`은 편집 가능한 **소스 입력**입니다. `dist`라는 이름 때문에 모두 빌드 산출물로 삭제하면 안 됩니다. `pnpm build`가 생성하는 `dist/client`, `dist/server`, `dist/vendor`, `.sites-runtime/assets.mjs`는 공개 저장소에 포함하지 않는 산출물입니다. 빌드는 기존 Cloudflare Worker 번들도 생성하지만, 공개본의 실행 명령은 그 Worker를 배포하지 않습니다.

공급자 어댑터와 일부 공통 수집 보조 모듈은 코드 검토를 위해 남아 있습니다. 이들을 실제로 연결하는 운영 구성과 Python 수집 환경은 포함하지 않았습니다. 기본 미리보기에서 사용하지 않는 스크립트를 직접 실행하는 것은 이 공개본의 검증 범위가 아닙니다.

## 공개본 실행 범위

`scripts/public-preview.mjs`는 공급자 자격증명을 상속하지 않고, 허용한 포트 설정만 읽습니다. 자동 작업, 뉴스·Telegram 수집, 가상자산 스트림, 외부 기업 자료 보완, AI 호출, 푸시 발송을 시작하지 않습니다. 서버의 outbound 클라이언트를 차단하고 브라우저에는 동일 출처 CSP를 적용합니다. 외부 TradingView 위젯도 이 설정으로 차단됩니다. 이 장치는 미리보기 실행 경로에 적용되는 방어이며 운영체제 차원의 샌드박스는 아닙니다.

외부 Pretendard CDN 연결은 제거했습니다. 공개 미리보기는 운영체제 기본 글꼴을 사용하므로 원래 화면과 글꼴 모양이 다를 수 있습니다. 차트와 PDF 라이브러리는 의존성에서 로컬 파일로 준비합니다.

투자 리서치 채팅 및 투자 생각 기능은 종료된 상태입니다. `/api/catalyst`와 `/api/theses` 계열은 410 응답을 반환합니다. `server/catalyst/`에는 기업 사업·매출 자료 등에서 재사용하는 모듈과 과거 구현이 남아 있으므로 디렉터리 이름이 활성 기능을 뜻하지는 않습니다. 공개본은 종료된 기능을 다시 켜지 않습니다.

## 데이터 제외와 시험 자료

다음 항목을 제외했습니다.

- `.env`, 비밀 키, Telegram 세션, 운영 SQLite DB와 수집 캐시
- 실제 공시·기사·리포트 본문 및 PDF, 실제 수집 응답 fixture
- 운영·배포 기록, QA 결과물, 개인 경로가 들어갈 수 있는 기존 문서
- 가상환경, `node_modules`, 기존 빌드 번들

기업·채널·운용사 목록, 실제 거래일 달력, 검토된 사건 및 일부 실체 식별 매핑은 import 구조를 유지하는 빈 설정으로 바꾸었습니다. 시험 fixture는 합성 자료만 선별했습니다. 계산 시험에 등장하는 숫자·날짜·티커 형태는 시험 입력이며 실시간 데이터나 투자 근거가 아닙니다. 모든 과거 시험을 공개본에 포함한 것은 아닙니다.

## 검증

```sh
pnpm test
pnpm test:smoke
```

`test:smoke`는 임시 loopback 포트와 메모리 DB에서 실행합니다. 원본 DB, `.env`, 외부 제공자를 사용하지 않습니다. 빌드 후 실행해야 합니다.

2026-10-28, Node.js v24.19.0에서 공개본 빌드와 격리 스모크가 성공했고, 선별 시험 **231개가 모두 통과**했습니다. 최초 sandbox 실행에서는 loopback 연결 제한으로 HTTP 시험 4개가 차단되어, 허용된 환경에서 전체를 다시 실행한 최종 결과입니다. PDF.js 하위 고지 9개의 복사본과 Worker asset map 보존도 확인했습니다.

이번 검증은 이미 설치된 의존성을 잠시 연결해서 수행했으며 새 설치 다운로드는 하지 않았습니다. 실제 외부 API·AI·운영 DB·브라우저 시각 검수는 수행하지 않았습니다. 명령별 결과와 제외 범위는 [공개본 구성 기록](PUBLIC-EXPORT.md)에 정리했습니다.

## 이용 조건과 출처

이 공개본은 코드 열람·평가를 위한 자료입니다. **프로젝트 자체의 재사용 라이선스는 아직 결정하지 않았으며, MIT 등의 재사용 허가를 부여하지 않습니다.** `package.json`의 `UNLICENSED`는 이 상태를 표시합니다. 재사용·재배포 범위가 필요하면 별도 확인이 필요합니다.

외부 라이브러리는 각각의 라이선스가 적용됩니다. 라이브러리 사용 조건이 프로젝트 전체에 대한 사용 허가를 대신하지 않습니다. 제3자 고지와 의존성 라이선스는 `THIRD-PARTY-NOTICES.md`와 `LICENSES/`를 참고하세요. 외부 금융 데이터의 이용 권한은 코드의 공개 여부와 별개입니다.

이 문서는 확인 가능한 파일 구조와 동작을 설명합니다. 개인별 작성 기여도, 개발 과정의 도구 사용 여부, 학내 제출 요건은 이 공개본에서 확정하지 않으며 별도로 검토할 항목입니다.
